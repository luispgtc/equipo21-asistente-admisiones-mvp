# Revalidación y equivalencia de estudios

> **EJEMPLO, no oficial.** Documento ficticio para probar el MVP. Debe sustituirse por el reglamento oficial de Control Escolar.

## Qué se puede revalidar

Se pueden revalidar materias de otra maestría, nacional o extranjera, con al menos 80 % de coincidencia de contenidos. Los diplomados y cursos sin valor curricular no se revalidan.

## Máximo de materias

Se revalida como máximo el 40 % de las materias del plan de estudios.

## Documentos para la equivalencia

- Certificado parcial o total de los estudios cursados.
- Programas de las materias con contenido y horas.
- Para estudios en el extranjero, apostilla y traducción oficial al español.

## Costo y tiempo del dictamen

El trámite cuesta 2,500 pesos (EJEMPLO). El dictamen tarda hasta 20 días hábiles desde que se entrega el expediente completo.

## Momento para solicitarla

La equivalencia se solicita durante el proceso de admisión o, a más tardar, antes de terminar el primer periodo. Las materias revalidadas aparecen como acreditadas, pero no cuentan para el promedio.
